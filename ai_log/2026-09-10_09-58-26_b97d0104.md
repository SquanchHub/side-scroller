## 1. `GameAction.ts` — the discrete-press state machine

A `GameAction` is a tiny state machine with four states: `RELEASED`, `BEGIN_PRESS`, `PRESSED`, `END_PRESS`. Each frame, `press()`/`release()` is called based on whether the key is currently down, advancing the state:

- key goes down: `RELEASED → BEGIN_PRESS → PRESSED` (stays `PRESSED` while held)
- key released: `PRESSED → END_PRESS → RELEASED`

`isBeginPress()` is true for exactly one frame — the frame the key transitions from up to down. That's the hook for "discrete press" actions like jump (and what you'll want for dash), as opposed to `isPressed()` which is true for every frame the key is held.
