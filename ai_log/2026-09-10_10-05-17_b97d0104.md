## `setVelocity` in `Sprite.ts` — does it overwrite both axes?

Yes, unconditionally. [Sprite.ts:65-72](src/sprites/Sprite.ts#L65-L72):

```ts
setVelocity(x: number, y: number) {
    if (x > 0) {
        this.setAnimation("right");
    } else if (x < 0) {
        this.setAnimation("left");
    }
    this.velocity.set(x, y);
}
```

`velocity.set(x, y)` replaces both components — no clamping (unlike `addVelocity`, which clamps to `MAX_SPEED` — [Player.ts:45-56](src/sprites/Player.ts#L45-L56)). So a dash can safely exceed `MAX_SPEED` by calling `setVelocity` directly, same as jump does for `JUMP_SPEED`. Side effect worth noting: it also flips the left/right animation based on the sign of `x`, but only when `x != 0` — passing `x == 0` leaves the current animation alone, which is how facing "persists" through moments of zero horizontal velocity.
