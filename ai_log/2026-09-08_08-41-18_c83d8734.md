## How the hook is wired up

`.claude/settings.json` registers two hooks that call the same script, `.claude/hooks/log_ai.py`:

- **`UserPromptSubmit`** → `log_ai.py prompt` (async): every time you send a message, it saves your raw prompt text to a scratch file (`/tmp/claude_ai_prompts.json`), keyed by session ID. Just staging data for later.
- **`Stop`** → `log_ai.py stop` (async): fires when the Claude Code session/turn ends. It:
  1. Pulls the saved prompt for this session ID back out of the scratch file.
  2. Parses the session's JSONL transcript (`transcript_path`) to pull out every tool call made and Claude's final text response.
  3. Writes a markdown file to `ai_log/` named `<timestamp>_<short-session-id>.md`, containing the prompt, a bulleted summary of tools used, and the truncated final AI response.
  4. Runs `git add` on that file (plus `ai_log/.gitkeep`) and `git commit` with message `ai_log: record session <id>`.
