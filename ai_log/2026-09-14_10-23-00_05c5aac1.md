## Map file format

Each `.txt` map is a grid of characters, one row per line, one tile per character column. `TILE_SIZE` in `resources.json:147` is **64px**, so each character occupies a 64×64px cell in the world.

**Line prefixes (metadata, not tiles):**
- `#` — comment line, ignored.
- `@` — map-level directive, e.g. `@parallax-layer bg1` / `@parallax-layer bg2` (background layers for parallax scrolling) and `@music music` (which music sprite/track to use). Seen in map1.txt:17-19; map2.txt has none, so those are optional/per-map.

- Space — empty tile (nothing rendered/solid).

- `a`–`z` (lowercase) — per the map1.txt comment header, animated tiles (not currently used in these two maps, but reserved).
